# Custom sound clips

Drop an `.mp3` here named after a sound to replace the built-in synthesized one, e.g. `jail.mp3`.

| File | When it plays |
| --- | --- |
| `jail.mp3` | A player goes to jail |
| `jailFree.mp3` | A player gets out of jail |
| `rentPaid.mp3` | Online: you pay rent |
| `rentGot.mp3` | Online: you collect rent |
| `rent.mp3` | Same-screen game: someone pays rent |
| `tax.mp3` | Tax or bill paid |
| `buy.mp3` | Property bought |
| `build.mp3` | House or hotel built |
| `card.mp3` | Fortune / Chance card drawn |
| `doubles.mp3` | Rolled doubles |
| `passStart.mp3` | Passed Start |
| `debt.mp3` | A player falls into debt |
| `bankrupt.mp3` | A player goes bankrupt |
| `win.mp3` | Game over |
| `turn.mp3` | Online: it's your turn |
| `dice.mp3`, `trade.mp3`, `pay.mp3`, `gain.mp3` | Dice roll, trade, other payments and income |
